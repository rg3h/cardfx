blurryBg
showing a blurry background on a card
If you create a card with an image and you use css object-fit:cover, you run the risk that important parts of the image get cut off:
 
Giraffes are large African hoofed mammals. They are the tallest living terrestrial animals on Earth.
.cardImage { object-fit: cover; }
If instead you make the card image be contained, then you might get pillars on either side:
 
 
Giraffes are large African hoofed mammals. They are the tallest living terrestrial animals on Earth.
.cardImage { object-fit: contain; }
One solution is to fill in the background of the parent image container with the same image, but scaled, blurred, and darkened. The CSS is simple, but only if the image is loaded in the HTML:
Giraffes are large African hoofed mammals. They are the tallest living terrestrial animals on Earth.
.cardImageContainerWithBlurryBg::before { background-image: url('./giraffe.jpg'); background-size: cover; content: ''; filter: blur(2px) brightness(70%); height: 100%; left: 0; position: absolute; top: 0; transform: scale(1.1); width: 100%; z-index: 1; }
If you load the image dynamically in javascript, then the filter does not work:
 
async function createCard(imageUrl, text) { const {card, imgContainer} = await createCard(imageUrl, text); // setting bg does NOT invoke css filters imgContainer.style.background = `url(${imageUrl})`; return card; }
To fix this, you can assign a css variable to the image and then in the javascript, change the value of the css var:
async function createCard(imageUrl, text) { const {card, imgContainer} = await createCard(imageUrl, text); // setting css var assigned to background // DOES invoke the filter imgContainer.style.setProperty( '--dynamicallyLoadedImg', `url(${imageUrl})` ); return card; }
Conclusion
Creating cards dynamically is useful, but variations in browsers, devices, and sizes can make layout tricky.
 
This is just another weird case where doing something dynamically in javascript may run afoul of the order in which the css and html layout values are evaluated.
