showing a blurry background on a card
If you create a card with an image and you use css (object-fit or background-size) 'cover', you run the risk that important parts of the image get cut off:
Here the image's css is using cover to have the image completely fill in the image container area, but this causes poor cropping.

If instead you make the card image be contained, then you might get pillars on either side:
Here the image's css is using contain to fit the entire image, but there are pillars since the image is taller than it is wide.

To fix this, you can fill in the background of the container with the same image, but scaled, blurred and darkened. This works, but only if the image is loaded statically:
To get rid of the pillars, the container behind the image also loads the image with a blur filter. This works because the image is loaded in the HTML.

To fix this, you can assign a css variable to the image and then in the javascript, change the value of the css var. This, oddly, does work:
